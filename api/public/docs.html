API Gerenciador de Tarefas

API REST desenvolvida com Node.js e Express para gerenciamento de tarefas. O projeto permite cadastrar, listar, atualizar, concluir e remover tarefas.

Node.js
Express
REST API
Vercel
JavaScript
Base URL: https://api-gerenciador-tarefas.vercel.app
GET
/tarefas

Retorna todas as tarefas cadastradas.

[
  {
    "id": "123",
    "titulo": "Estudar Node.js",
    "descricao": "Aprender Express",
    "concluida": false
  }
]
POST
/tarefas

Cria uma nova tarefa.

{
  "titulo": "Estudar backend",
  "descricao": "Aprender APIs REST"
}
PUT
/tarefas/:id

Atualiza uma tarefa existente.

{
  "titulo": "Backend atualizado",
  "descricao": "Nova descrição"
}
PATCH
/tarefas/:id/concluir

Marca uma tarefa como concluída.

{
  "mensagem": "Tarefa concluída"
}
DELETE
/tarefas/:id

Remove uma tarefa pelo ID.

{
  "mensagem": "Tarefa removida"
}
